Agent preset controls

A mock of a mouse-first way to set a group's or a workspace's agent preset. Today both can only be set from the command palette. The mock uses example groups and the three presets fab ships.

1 · Live mock — click a group or the workspace, then "Agent preset…"

A row shows the preset name when the group or workspace has its own preset.

  • A preset line that is always there. It shows the preset new tabs will use and where it comes from, including when the group inherits.
  • An "Agent preset…" row next to "Change color…", on both the group card and the workspace card.
  • A chooser that lists the presets with their one-line descriptions, plus "inherit" and "none". It only picks a preset; what a preset contains is shown in Settings > Agent.
  • The preset name on the row when a group or workspace has its own preset, so you can see it without opening the card.
  • The palette actions stay as they are and open the same chooser list.
