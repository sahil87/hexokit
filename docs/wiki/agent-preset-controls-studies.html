Agent preset controls

A mock of a mouse-first way to set a group's or a workspace's agent preset. Today both can only be set from the command palette. The mock uses example groups and the three presets fab ships.

  • A preset line that is always there. It shows the preset new tabs will use and where it comes from, including when the group inherits.
  • An "Agent preset…" row next to "Change color…", on both the group card and the workspace card.
  • A chooser that lists the presets with their one-line descriptions, plus "inherit" and "none". It only picks a preset; what a preset contains is shown in Settings > Agent.
  • The preset name on the row when a group or workspace has its own preset, so you can see it without opening the card.
  • The palette actions stay as they are and open the same chooser list.

3 · Settings > Agents — pick the machine default; create, edit and delete presets

The page does two separate things. Picking is one dropdown. What a preset contains lives only in the Presets section. A preset made here shows up in the chooser in section 1.

4 · What changes on the Settings page

  • Picking and editing are separate. "Default preset" only selects. The role table only edits the preset chosen in the list beside it.
  • The Customize grid becomes the preset editor. Today's table of roles (CLI, model, effort) is kept, but it edits a named preset instead of loose machine-wide settings.
  • Loose machine-wide settings stop being a third thing. If some exist, the page says so and offers to move them into a preset or clear them. They are confusing today: they override the machine default but lose to a group's or workspace's preset.
  • No Save button. Each field is written when you change it, as on the page today. A new preset exists as soon as it has a name.
  • Built-in presets are read-only. Duplicate one to change it.
  • Duplicate and rename ask for a name. A rename repoints the machine default and any group or workspace using the preset. Tabs already running remember the old name and fall back to the default, and the rename form says so.
  • Dispatch settings stay as they are.

Settled

  • Row marker: the preset name.
  • The chooser picks a preset only; no role breakdown.
  • Selection (machine, workspace, group, one tab) is separate from creating, editing and deleting presets, which happens only in Settings > Agents.
